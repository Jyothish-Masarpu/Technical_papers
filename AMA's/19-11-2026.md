### 1. Anoop Vantagodi: What is a Higher-Order Function in Python?
A higher-order function is a function that accepts another function as an argument or returns a function as its result.

Examples: `map()`, `filter()`, and `sorted()`.

### 2. Kiran B L: What is the Use of SAVEPOINT in SQL?
`SAVEPOINT` creates a point within a transaction to which we can roll back without cancelling the entire transaction.

Example:
```sql
BEGIN;
INSERT INTO students VALUES (1, 'John');
SAVEPOINT sp1;
INSERT INTO students VALUES (2, 'David');
ROLLBACK TO SAVEPOINT sp1;
COMMIT;
```

### 3. Kummari Amaresh: What are Primary Key and Foreign Key?
- **Primary Key:** Uniquely identifies each record in a table. It cannot contain NULL values or duplicate values.
- **Foreign Key:** Creates a relationship between two tables by referencing a primary key or another unique key.

### 4. Kuppireddy Sivashankara Reddy: What is the Difference Between RAM and ROM?
- **RAM:** Temporary, volatile memory used to store data and programs currently being processed. Data is lost when power is turned off.
- **ROM:** Non-volatile memory used to store firmware and instructions. Data is retained even when power is turned off.

### 6. Mohd Saad Shaikh: What is `||` in SQL?

Example:

### 7. Moyya Naveen: How to Remove Multiple Whitespaces in a String in Python?
We can use `split()` and `join()` to remove extra spaces and keep only a single space between words.

Example:
```python
text = "Hello    World   Python"
result = " ".join(text.split())

print(result)
```
**Output:**
```text
Hello World Python
```

### 8. Mudrakola Sai Pavan: What is ROLLUP in SQL?
`ROLLUP` is used with `GROUP BY` to generate subtotals and a grand total for grouped data.

Example:
```sql
SELECT department, SUM(salary)
FROM employees
GROUP BY ROLLUP(department);
```
It returns the total salary for each department along with the overall total.

### 9. Neha Sunil Magadum: What is the Difference Between CHAR and VARCHAR?
- **CHAR:** Fixed-length character data type. It reserves the specified length.
- **VARCHAR:** Variable-length character data type. It stores only the required characters, up to the specified limit.

Example:
- `CHAR(10)` reserves a fixed length of 10 characters.
- `VARCHAR(10)` stores up to 10 characters.

### 10. Palepu Veerababu: What is the Use of Locking Mechanisms?
Locking mechanisms control concurrent access to database resources and prevent conflicts when multiple transactions access or modify the same data.

Common types:
1. **Shared Lock:** Allows multiple transactions to read data.
2. **Exclusive Lock:** Allows one transaction to modify data while preventing conflicting access.

### 11. Parameswaran R: What is the Difference Between Shallow Copy and Deep Copy?
- **Shallow Copy:** Creates a new object but shares references to nested objects with the original object.
- **Deep Copy:** Creates a new object and recursively copies nested objects, so changes to nested objects do not affect the original.

Python provides the `copy` module for both operations.

### 12. Pavan Kumar: How Does Python Handle the Diamond Problem?
Python handles the diamond problem using **Method Resolution Order (MRO)**.

MRO determines the order in which Python searches for methods in multiple inheritance. Python uses the C3 linearization algorithm to maintain a consistent method resolution order.

We can check the order using:
```python
print(ClassName.mro())
```

### 13. Raghu B S: In Which Structure Is Data Stored in PostgreSQL?
PostgreSQL stores table data using **8 KB pages**. These pages are organized into database files on disk.

A table is internally stored as a heap, and its records are stored in rows within these pages.

### 14. Shakthivel: What is the Use of COMMIT in SQL?
`COMMIT` permanently saves all changes made during the current transaction.

Example:
```sql
BEGIN;
UPDATE employees
SET salary = 50000
WHERE id = 1;
COMMIT;
```
After `COMMIT`, the transaction's changes are saved and cannot be undone using `ROLLBACK`.

### 15. Sunkara Prasanth: Is self Mandatory in OOP?
`self` is not a reserved keyword in Python, but the first parameter of an instance method is required to refer to the current object.

We can use another name instead of `self`, but `self` is the standard Python convention.

### 16. Varad Rajesh Barbhai: Explain replace() in Python.
`replace()` is a string method used to replace occurrences of a specified substring with another substring.

Syntax:
```python
string.replace(old, new, count)
```

Example:
```python
text = "Hello World"
result = text.replace("World", "Python")

print(result)
```
**Output:**
```text
Hello Python
```

It returns a new string because strings in Python are immutable.
