### 1. Anoop Vantagodi: What is Method Overriding?

### 3. Kiran B L: Difference Between `==` and `is`?
- `==` compares values.
- `is` compares object identity (whether both references point to the same object).

### 5. Kuppireddy Sivashankara Reddy: What Does L Represent in SOLID?
L stands for **Liskov Substitution Principle**. Child objects should be replaceable for parent objects without breaking program behavior.

### 6. Manish Nalumachu: What is the Use of Git Initialization?
`git init` initializes a directory as a Git repository and creates a `.git` directory to manage version control.

### 7. Mohd Saad Shaikh: What is an Abstract Class?
A class that cannot be instantiated directly and is designed to be inherited by other classes.

### 8. Moyya Naveen: How to Create an Abstract Class?
Use the `ABC` class and `@abstractmethod` decorator from the `abc` module.

```python
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def sound(self):
        pass
```

### 9. Mudrakola Sai Pavan: What Happens if We Use break in a Nested Loop?
`break` terminates only the nearest enclosing loop. The outer loop continues execution.

### 10. Neha Sunil Magadum: What is the Use of super()?
`super()` is used to access parent-class methods and constructors from a child class.

### 11. Palepu Veerababu: Why Do We Need Classes and Objects?
Classes organize data and behavior into reusable structures. Objects are instances of classes used to access their attributes and methods.

### 12. Parameswaran R: Can a Dictionary Have a List or Tuple as a Key?
- List: No, because it is mutable and unhashable.
- Tuple: Yes, if all its elements are hashable.

### 13. Pavan Kumar: What is the Time Complexity of Removing a Dictionary Key?
- Average case: O(1)
- Worst case: O(n)

### 14. Raghu B S: Does Python Support Overriding or Overloading?
Python directly supports method overriding. Traditional method overloading is not directly supported, but similar behavior can be achieved using default arguments and `*args`.

### 15. Shakthivel: Is It Necessary to Use self?
The first parameter of an instance method is required to refer to the current object, but its name need not be `self`. However, `self` is the standard convention.

### 16. Sunkara Prasanth: What is MRO?
MRO stands for **Method Resolution Order**. It defines the order in which Python searches for methods in an inheritance hierarchy.

### 17. Varad Rajesh Barbhai: What is Coupling in OOP?
Coupling represents the dependency between classes.
- Tight coupling: High dependency.
- Loose coupling: Low dependency.

Loose coupling is preferred for maintainable and flexible applications.
